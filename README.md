
# Task Manager Lite

## Project Objective

A simple full-stack web application for managing everyday tasks.
Users can create, view, edit, complete, and delete tasks.

## Features

- Create tasks with a title and optional description
- View all saved tasks
- Edit existing tasks
- Mark tasks as completed or pending
- Delete tasks
- Store tasks persistently in a database

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, FastAPI
- **Database:** SQLite
- **Testing:** Pytest
- **Version Control:** Git and GitHub

## Project Status

Currently in the initial development and setup phase.
